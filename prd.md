# Product Requirements Document (PRD)

## 1. Обзор продукта (Product Overview)
**Название приложения:** HiLight
**Описание:** HiLight — это мобильное образовательное приложение (EdTech), предназначенное для работы с конспектами, цитатами и заметками из книг. Приложение использует искусственный интеллект (AI-ассистент "Lumi") для помощи в осмыслении прочитанного и взаимодействия с книжным материалом.

## 2. Целевая аудитория (Target Audience)
- Студенты и учащиеся.
- Исследователи и академические работники.
- Любители чтения, стремящиеся систематизировать свои знания и заметки.
- Люди, предпочитающие комбинировать различные форматы заметок (текст, голос).

## 3. Основной функционал (Core Features)

### 3.1. Умная лента заметок (Notes Feed)
Главный экран приложения отображает список карточек (заметок) пользователя. 
Поддерживаются 3 основных типа карточек:
- **Scanned Quotes (Отсканированные цитаты):** Цитаты, распознанные из текста (возможно, через OCR). Акцентный цвет — оранжевый.
- **Voice Notes (Голосовые заметки):** Аудиозаписи мыслей пользователя с визуализацией звуковой волны (waveform). Акцентный цвет — фиолетовый.
- **AI Insights (Инсайты от ИИ):** Сгенерированные ИИ выводы, резюме или интересные факты на основе прочитанного. Акцентный цвет — зеленый.

### 3.2. Взаимодействие с ИИ (Lumi AI Assistant)
- **Умная строка поиска/ввода ("Ask Bar"):** Расположена в нижней части главного экрана. Позволяет пользователю задавать вопросы ИИ-ассистенту Lumi по контексту текущей книги (placeholder: *"Ask Lumi anything about this book.."*).
- **Интерактивные ответы:** ИИ генерирует инсайты и отвечает на вопросы пользователя, помогая глубже понять материал.

### 3.3. Навигация и UI
- **Верхняя панель (Top Bar):** Отображает логотип, кнопку добавления новой заметки (+) и профиль пользователя.
- **Нижняя панель навигации (Bottom Navigation Bar):** Для переключения между основными разделами приложения (например, Главная, Библиотека, Профиль).

## 4. Технический стек и Архитектура (Tech Stack & Architecture)
- **Фреймворк:** Flutter (SDK `^3.6.0`).
- **Язык:** Dart.
- **Управление состоянием (State Management):** 
  - Основной инструмент: `flutter_riverpod` (v2.5.1).
  - Архитектура также закладывает возможность использования BLoC (присутствует директория `BLoC`).
- **Архитектурный паттерн:** Feature-Driven Development (FDD).
  - `lib/app/`: Инициализация приложения (`HiLightApp`).
  - `lib/core/`: Общие константы (`app_colors.dart`) и темы (`app_theme.dart`).
  - `lib/features/`: Изолированные фичи. Например, `home`, разделенная на слои `data`, `domain`, `presentation` (содержит `providers`, `screens`, `widgets`).

## 5. Дизайн и UX (Design & UX Guidelines)
Приложение использует светлую, "бумажную" тему, создающую комфортную среду для чтения:
- **Background:** `#F5F0E8` (теплый белый/кремовый).
- **Surface:** `#FFFFFF` (чистый белый для карточек).
- **Text:** Основной — `#2C2C2A`, второстепенный — `#5F5E5A`.
- **Card Accents:** 
  - *Quote:* `#F5A623` (Оранжевый)
  - *Voice:* `#7F77DD` (Фиолетовый)
  - *AI Insight:* `#5DCAA5` (Зеленый)
- **Скругления и тени:** Мягкие тени для `Ask Bar` и скругленные углы карточек для создания дружелюбного и современного интерфейса.

## 6. План дальнейшего развития (Roadmap / Next Steps)
1. Реализовать логику сканирования текста (OCR) для Scanned Quotes.
2. Интегрировать запись и транскрибацию аудио для Voice Notes.
3. Подключить бэкенд / LLM (например, OpenAI или Gemini) для работы AI-ассистента Lumi и генерации AI Insights.
4. Добавить локальное хранение (например, Hive или Isar) или облачную синхронизацию заметок (Firebase / Supabase).
